# Record a material conversation or completed client update

Read CLAUDE.md. Run `npm run immigration -- log "<matter>" '<note JSON>' --json`. Read the result before answering. List ambiguous matches for the operator.

Use kind internal, oral or client-update, with name, author, body and happened_on. client-update requires confirmed_ref showing an actual communication. A draft is not a completed update.

Use only recorded facts. Never send, lodge, infer visa eligibility or process a payment. Drafts remain in drafts/ until a person reviews them.
