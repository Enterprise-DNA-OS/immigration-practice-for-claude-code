# Record an actual received decision

Read CLAUDE.md. Run `npm run immigration -- record-decision "<application>" YYYY-MM-DD "<outcome>" --json`. Read the result before answering. List ambiguous matches for the operator.



Use only recorded facts. Never send, lodge, infer visa eligibility or process a payment. Drafts remain in drafts/ until a person reviews them.
